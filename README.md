This is a simple data analysis project wherein the goal is to answer the following questions:<br />
  -Which company type (comp_type) has the lowest profitability ratio?<br />
  -Which company type has the highest leverage ratio?<br />
  -Is there a relationship between profitability and leverage ratio for real_est (real estate) type companies?<br />

Profitability ratio is a type of accounting ratio that helps in determining the financial performance of business at the end of an accounting period. Profitability ratio shows how well a company is able to make profits from its operations.
While leverage ratio is a financial metric that compares a company's debt to its assets, equity, or earnings. It's used to assess a company's financial health and ability to pay its debts. Also known as debt-to-equity ratio.<br /><br />

The two files included are Balance_Sheet.xlsx and Income_Statement.xlsx. These contain information from the financial statement of the a particular "company."<br />
The analysis can be found in the file building_financial_report.ipynb.
